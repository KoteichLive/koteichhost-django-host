Koteich Host — Панель управления игровыми серверами

Исходный код панели управления для хостинга игровых серверов koteichhost.ru.

Это многофункциональная веб-платформа, предназначенная для удобного развертывания и управления игровыми серверами, а также для создания сообщества вокруг хостинга.

🚀 Ключевые возможности
📊 Дашборд: Единый центр управления для отслеживания состояния ваших сервисов, ресурсов и уведомлений.

🎮 Заказ серверов через GameAP: Интеграция с популярной системой GameAP для автоматизированного создания и настройки игровых серверов (например, для Minecraft, CS:GO, GMod и др.).

👁️ Просмотр серверов: Удобный интерфейс для мониторинга статуса, онлайна и основных параметров ваших игровых серверов.

📈 Мониторинг ресурсов: Отслеживание в реальном времени потребления ресурсов (CPU, RAM, Disk) вашими серверами и веб-хостингом.

⚖️ Аукцион: Уникальная система торгов, где пользователи могут выставлять на продажу или покупать излишки ресурсов, моды и другие цифровые товары за внутреннюю виртуальную валюту.

💬 Технический форум: Площадка для обсуждения технических вопросов, получения помощи и обмена опытом между пользователями хостинга.

🔧 Мессенджер / Чат: Встроенная система общения, позволяющая пользователям и администрации быстро решать вопросы и взаимодействовать друг с другом.

🤖 API для промокодов: Гибкий API для создания и активации промокодов. Интегрируется с экосистемой Koteich, включая ботов и рекламную биржу.

🛠 Технологический стек
Бэкенд: PHP, MySQL, GameAP

Фронтенд: HTML, CSS, JavaScript (возможно, используется фреймворк, например, Bootstrap, Vue.js, React - уточните)

Прочее: Веб-сервер (Nginx/Apache), система очередей (например, Redis)
